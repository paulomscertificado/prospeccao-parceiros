Visuais das campanhas

O HTML do e-mail e a imagem do WhatsApp que as campanhas podem usar (IA SDR e Empresas novas).
CampanhasEmpresas novas

Como funciona

  • E-mail: sai com duas versões, o texto de sempre e o HTML do visual. No HTML, escreva {{ '{{mensagem}}' }} onde deve entrar o texto do toque (já personalizado para cada empresa). Também dá para usar {{ '{{nome}}' }}, {{ '{{empresa}}' }}, {{ '{{cidade}}' }}, {{ '{{vendedor}}' }} e {{ '{{descadastro}}' }} (o link para sair da lista; se não usar, ele entra sozinho no fim).
  • WhatsApp: sai a imagem do visual com o texto do toque embaixo. Para proteger o número, a imagem só vai para quem já conversou com a MS; para contato frio sai só o texto.
  • Na campanha você escolhe o visual, os canais e se ele vale do 2º toque em diante (recomendado) ou em todos.
